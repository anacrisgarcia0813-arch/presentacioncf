Seguridad del sistema

Cada persona ve
exactamente lo que le corresponde.

La seguridad no es un extra — es la base del sistema. Cada usuario tiene credenciales únicas, acceso por rol definido y toda su actividad queda registrada.

🔐
Acceso por usuario y contraseña
Cada persona del equipo tiene su propio correo y contraseña de acceso. Nadie comparte credenciales. El sistema detecta accesos sospechosos.
👁️
Control por roles
Cada rol tiene permisos exactos. El inversionista solo ve su inversión. El equipo de cobranza no ve información de obras. Nadie accede a lo que no le corresponde.
🔒
Cifrado de extremo a extremo
Toda la información viaja cifrada entre el dispositivo y el servidor. Los datos en reposo también están cifrados. Estándar bancario.
☁️
Infraestructura cloud
Alojado en servidores de alta disponibilidad con backups automáticos diarios. 99.9% de uptime garantizado. Los datos nunca se pierden.
🛡️
Datos privados y exclusivos
Los datos de Estructurar Futuro nunca se comparten con otros clientes ni terceros. Infraestructura dedicada. Total privacidad garantizada.
📱
Autenticación de dos factores
Para roles críticos (CEO, Director Financiero) se puede activar doble autenticación por SMS o app autenticadora. Capa adicional de seguridad.

Sistema de pagos centralizado

Cada pago registrado.
Automático. Verificable en línea.

El objetivo es que cada vez que un arrendatario realice su pago, este se refleje automáticamente en el sistema — sin que nadie tenga que ingresarlo manualmente. Fin a los pagos duplicados, los comprobantes perdidos y la mora que nadie vio llegar. La forma de implementarlo depende de lo que Estructurar Futuro necesite y tenga disponible hoy.
OPCIÓN 01
API bancaria directa
Conexión directa al banco de Estructurar Futuro mediante API oficial. Cada pago entrante se detecta y registra automáticamente en tiempo real.
  • Detección automática de pagos entrantes
  • Sin intervención manual del equipo
  • Conciliación bancaria automática
  • Alertas instantáneas de pago recibido
  • Historial completo integrado
Requiere convenio con el banco
OPCIÓN 02
Pasarela de pago
El arrendatario ingresa a su portal, hace clic en "Pagar" e ingresa sus datos. La plataforma se conecta a una pasarela (Wompi, PayU, Mercado Pago) y procesa el pago directamente.
  • El arrendatario paga desde el portal
  • Tarjeta, PSE, efectivo o transferencia
  • Registro automático en el sistema
  • Comprobante generado automáticamente
  • Integración con Wompi, PayU, Mercado Pago
Recomendada · Implementación rápida
OPCIÓN 03
Sistema propio a la medida
Construimos el flujo de pagos exactamente como Estructurar Futuro lo necesite — según su proceso interno, sus acuerdos comerciales y sus formas de recaudo actuales.
  • Diseñado para el proceso actual de EF
  • Integración con sistemas existentes
  • Flujo aprobación y verificación interno
  • Registro manual con validación automática
  • Escalable a API bancaria o pasarela
